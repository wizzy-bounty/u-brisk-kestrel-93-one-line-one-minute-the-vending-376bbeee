Entry for the [make.fun](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) competition **"One Line, One Minute: The Vending Machine Pickup Line Contest"** — write one pickup line, 200 characters at most, that a vending machine would use on a passing human.

## The line

> I've hummed for a thousand strangers, but you made my coils spin — press B4, this one's on the house.

## How it works

`main.py` (Python standard library only, deterministic, no network) writes that single line to `/output/entry.txt`. The gate requires UTF-8 text of 1–200 characters, not only whitespace.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
